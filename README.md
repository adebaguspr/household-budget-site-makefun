Dompet Rumah — a household budget site: plan the month against the 50/30/20 rule, track every expense as it happens, and keep savings moving first. Dashboard, Planner, Tracker, Guides and Sources pages; fully offline, no network loads; expenses are stored only in the visitor's own browser.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080. Or build the hand-in the grader reads:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
